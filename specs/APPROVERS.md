# Default approvers (used when the issue form has no Approver)

| Category | Approver (GitHub login) |
|---|---|
| `_ORD` Provider Orders | @APPROVER-LOGIN-1 |
| `_RET` Returns | @APPROVER-LOGIN-2 |
| Both / unclear | @APPROVER-LOGIN-1 |

Maintained by the code owner. Approvers need only a GitHub account that receives notification emails — they are @-mentioned on the spec pull request, and only the named approver's Approve (or a collaborator's) confirms the spec. No repository role is required.
